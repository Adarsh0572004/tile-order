# Tile Order

Estimate tile quantities from floor area, tile dimensions and a waste allowance. All dimensions use centimetres.

## Quick start

Use Python 3.10 or newer. All dependencies are in the standard library.

```sh
python app.py 400 300 30 30 10
```

The example output includes `Tiles to order: 147`. Run `python app.py --help` for the available options.
